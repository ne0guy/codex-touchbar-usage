Codex Usage Bar 0.4.0 adds native Touch Bar customization and a new app icon.

- Choose five-hour and weekly usage, bars, percentages, reset times, and token counts.
- Preview changes instantly and save preferences automatically.
- Select remaining or used usage, compact bars, and lime, sky blue, or amber.
- Restore the compact v1 layout with one click.
- Open settings from the menu-bar chart icon or by reopening the app.

Download `CodexUsageBar-v0.4.0-arm64.zip`, extract it, and run `./install.sh` from the extracted folder. The installer upgrades an existing installation. Use `./uninstall.sh` to remove it.

Requires an Apple Silicon MacBook with a Touch Bar and macOS 12 or later. A local Codex sign-in is required for official usage refresh. ZCode retains its existing layout.

This build is ad-hoc signed and has not been Apple-notarized. Verify the supplied SHA-256 checksum. If macOS blocks it, use System Settings > Privacy & Security > Open Anyway.

The Git tag `v1` preserves the previous compact layout. The `codex/customization-app` branch contains the customization work.
